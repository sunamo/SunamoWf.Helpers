# SunamoWf.Helpers

## Short description

Pomocné třídy pro práci s obrázky a hledáním ve WinForms appkách (PicturesForms, PicturesHelperFw, SearchingInLbWF, TextBoxPath). Balíček je self-contained a nereferencuje jiné Sunamo balíčky, potřebný kód má zkopírovaný lokálně jako internal.
